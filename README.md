# Freedom Skill Hub — Render static site

This is a self-contained static website. The logo, favicon, styling, and scripts are embedded in `index.html`.

## Deploy on Render

1. Create a GitHub repository and upload `index.html` and this README to the repository root.
2. In Render, choose **New + → Static Site**, then connect the repository.
3. Set **Build Command** to blank and **Publish Directory** to `.`.
4. Click **Create Static Site**.

The enquiry form opens WhatsApp to the existing counsellor number with the visitor's details prefilled. The visitor must review and press **Send** in WhatsApp; this static site does not send messages silently in the background.
